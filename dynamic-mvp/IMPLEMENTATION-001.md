## 4. Schema 转换（仅方言转换，不改语义）

源：`05_Database_Design/V0.2/08-schema.sql`（SQLite 3）
产出：`dynamic-mvp/db/ddl/01-schema-country-library.postgresql.sql`

| 转换 | SQLite（V0.2） | PostgreSQL |
|---|---|---|
| T1 | `INTEGER PRIMARY KEY AUTOINCREMENT` | `INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`（BY DEFAULT 允许显式写入原始 ID） |
| T2 | `TEXT`（DATETIME） / `DEFAULT (datetime('now'))` | `TIMESTAMPTZ` / `DEFAULT now()` |
| T3 | `REAL`（latitude / longitude） | `DOUBLE PRECISION`（**未用**注释建议的 `NUMERIC(8,5)`：pg 驱动会把 NUMERIC 序列化为字符串，会破坏 `world-map.js` 的 `project(lng, lat)` 数值投影） |
| T4 | 注释中的长度意图（`VARCHAR(100)` 等） | 逐字段恢复为 `VARCHAR(n)` |
| T5 | CHECK / UNIQUE / FK（RESTRICT、CASCADE、UPDATE CASCADE）/ 4 条索引 | **全部保留** |

未包含 Award / Award_Result / Case_Project / Source / 五张 `_source` 表 ——
它们不是本切片，继续由 `data/*.json` 提供。

## 8. Adapter（唯一改造文件：`js/data-loader.js`）

```
library.js / libraries.js / country.js / home.js / world-map.js …
        ↓（函数签名不变）
loadAllCoreData() / loadCountries() / loadLibraries()
        ↓
Data Adapter（本文件内部）
   ↙              ↘
Directus API     data/*.json
Library          Award
Country          Award Result
                 Case
                 Source
```

- `DATA_SOURCE_MODE = "api"`：`api`（默认）或 `json`（回退开关，无需改动任何页面代码）
- `fetchCollection()`：读 `{data: [...]}`；网络 / HTTP / 解析 / 载荷异常统一抛 `DataLoadError`
  （新增 `reason = "api"`）
- `normalizeDate()`：把 `...T00:00:00.000Z` 归一回 JSON 契约的日期形态
  （`last_updated → 2026-09-19`，`created_at → 2026-09-19T04:00:00`），保证页面显示与排序不变
- **不做客户端 status 过滤**（过滤已在 API 权限层完成）
- 未改：`library.js`、`library.html`、`?id=` URL、`data/*.json`、CSS / 设计令牌

## 14. Known Issues / Limitations

1. **Hybrid Transitional Architecture**：Award / Award Result / Case / Source 仍读 JSON。
   Issue §3 要求的「Library 页面渲染必需关联数据」目前由 JSON 侧满足，页面不退化；
   全量迁移属 B2，本轮不做。
2. **适配层写死 `http://localhost:8055`**：仅适用于本地 MVP；
   部署前必须由人工确认 API 基址与 CORS 策略（本轮未部署）。
3. **Directus 未做容器数据持久化到工作区**：数据在 docker volume `glp-mvp_postgres-data`，
   销毁卷后需重新 `docker compose up -d` 由 init 脚本重建（已验证可重建）。
4. **`last_updated` 未在写入时自动刷新**：AC2 只改 `city`，未触碰治理语义；
   「更新即刷新 last_updated」属 B3 审核流程范围。
5. **未实现父子状态链的服务端强制**：子对象（Award Result / Case）仍在 JSON 侧，
   其可见性沿用前台既有规则（Stage 8 基线行为，无回归）。
6. **Directus 11.17.4 有 12.4.1 可用更新**：本轮不升级（避免引入无关变量）。
