The map is an entry point — the database is the core. Map data comes from the same countries.json and libraries.json used everywhere else; no separate map dataset exists. Library markers are drawn only when real latitude/longitude values are present.

Map Legend

  • Country / region browsing marker — positioned at the country centre coordinate stored in countries.json. It marks a country, not an individual library location.
  • Library marker — drawn only when a library has real latitude / longitude values (currently none, see the note below)
  • Simplified landmass outline (local vector basemap — MapLibre GL JS, vendored, no online tiles)
