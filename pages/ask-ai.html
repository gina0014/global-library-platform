Explore the knowledge base using natural language. Answers are generated by a scripted query engine that searches the local runtime dataset — this is a prototype interface, not a real AI system.

Prototype / Demo. This page does not call any AI model or external API, requires no API key and has no backend. Questions are matched by keywords against the local JSON dataset — it is a rule-based prototype, not a language model.
How a future production version would work (not implemented here). A full system is planned to combine three layers:
  • Structured Database Query — precise filtering over the normalised Country / Library / Award / Award Result / Case / Source model.
  • Knowledge Retrieval — semantic retrieval across validated records and their relations.
  • Source-grounded AI — generated answers that cite the underlying sources, so every claim can be traced back to its evidence.

None of these layers are implemented in this prototype: this page only runs scripted keyword queries over the local dataset.
