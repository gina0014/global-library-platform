Ask AI

Explore the knowledge base using natural language. Every answer is retrieved from the platform dataset and composed from real records — facts are never generated.

Data-grounded answers. This assistant resolves your question against the live platform dataset (Country / Library / Award / Award Result / Case / Source) and composes the answer from the records it finds, citing the underlying sources. It is retrieval + template composition: no language model is called, no API key is used, and no fact is invented. When the data cannot answer a question, it says so instead of guessing.
What a future production version may add (not implemented here).
  • Generative language model — natural-language phrasing on top of the same retrieved records, introduced as a deployment / configuration step.
  • Semantic retrieval — synonym and paraphrase tolerance beyond the current structured matching.

Neither is required to answer the questions below: the grounding layer is already the platform dataset, so adding a model later changes phrasing, not evidence.
